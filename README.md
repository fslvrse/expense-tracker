# Expense Tracker

Expense Tracker is a web application that allows users to manage their personal expenses. It provides a simple and intuitive interface to add, view, and delete expenses.

## Features

- Add new expenses with a description, amount, and date
- View a table of all recorded expenses
- Delete individual expenses
- Persist expense data across sessions using local storage
